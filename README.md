# Atinder Pal Singh — AI/ML Portfolio

A static, recruiter-focused portfolio inspired by the editorial structure and interaction quality of modern senior software/AI portfolios.

## Included
- Responsive single-page portfolio
- Animated AI network hero
- Dark/light theme toggle
- Project case-study modal
- HealthKart + UniGuide + cloud + predictive analytics projects
- Experience timeline based on the supplied resume
- Technical arsenal based on the supplied resume
- Downloadable resume in `assets/`
- No build step required

## Run locally
Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Personal links
The resume supplied for this build contains a LinkedIn label but no LinkedIn URL, so the LinkedIn button is intentionally a generic placeholder link. Replace it in `index.html` with the actual profile URL before publishing.

## Important
Company names in the supplied resume are masked as `XXXXX` and `XXX XXXX`; the portfolio preserves that rather than inventing employer names.
